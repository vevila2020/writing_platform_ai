# AI 痕迹扫描参考

本文件是 `novel-deslop` 的只读盘点清单。扫描只用于找候选，不按命中数量机械替换；每一处都要结合语境判断是 AI 痕迹还是作者有意选择。

## 扫描命令

在项目根目录运行，把 `chapters/` 换成目标目录或文件。命令只读，不会修改正文。

```bash
# 万能副词与动作修饰
rg -n --pcre2 '缓缓|淡淡|微微|轻轻|默默|静静|不禁|不由得|下意识' chapters/

# 情绪贴标签
rg -n --pcre2 '感到(愤怒|恐惧|悲伤|震惊|紧张|害怕|绝望)|心中一凛|心头一紧|五味杂陈|百感交集' chapters/

# 全员同一套反应
rg -n --pcre2 '瞳孔(骤|猛)?缩|倒吸一口凉气|全场(寂静|哗然)|鸦雀无声|空气(仿佛)?凝固' chapters/

# 解释句与总结句
rg -n --pcre2 '这意味着|换句话说|也就是说|他知道，?这代表|这说明|他终于明白|这一刻' chapters/

# 升华与模糊指代
rg -n --pcre2 '也许，?这就是|某种(说不清|难以言说)|说不清道不明|命运的齿轮' chapters/

# 过度对仗
rg -n --pcre2 '不是.{1,20}而是|既.{1,20}又|一边.{1,20}一边' chapters/
```

`rg` 不可用时，用编辑器查找或 `grep -nE` 替代；不要为了跑扫描中断写作。

## 信号与改法

| 信号 | 为什么像 AI | 最小改法 |
| --- | --- | --- |
| 段末总结 / 感悟 | 模型喜欢替读者下结论 | 删掉，落在动作、对话或后果上 |
| 「缓缓 / 淡淡 / 微微」+ 动作 | 万能副词抹平具体性 | 换成具体动作、力度、速度或生理反应 |
| 「感到愤怒 / 恐惧」 | 直接告诉读者情绪 | 写他此刻做不成什么、身体哪里紧、下一步做什么 |
| 全员同一套反应 | 模型复用同一套反应模板 | 给每个角色专属的小动作、句长和回避方式 |
| 「这意味着 / 换句话说」 | 展示后解释，不信任读者 | 删掉解释句，保留可推断的细节 |
| 对话一问一答 | 信息播报，没有诉求 | 加试探、回避、打断、答非所问或沉默 |
| 抽象大词 | 用概念代替画面 | 换成具体物件、动作、数字或感官细节 |
| 段落长度均匀 | 节奏没有疏密 | 紧张处拆短句，平静处允许长段 |
| 连续排比 / 对仗 | 语言过于整齐 | 打散句式，只保留最有力量的一处 |
| 章末安全着陆 | 模型倾向于收束情绪 | 留一个未解决的问题、未回应的请求或不安感 |

## 误报与例外

- 作者有意使用的口头禅、冷硬短句、重复、留白，不要当 AI 痕迹清理。
- 人物说话可以口语、可以重复；叙述者的用词和人物对话要分开判断。
- 「缓缓」在确实需要表现速度时可以使用；判断标准是它有没有提供新信息。
- 情绪词不是禁用词；如果前后已经有具体动作和后果，直写情绪可以保留。
- 扫描命中为零，不代表没有问题；叙事焦点、信息边界、段落节奏仍要人工检查。

## 人工检查项

正则覆盖不到、但更影响阅读的部分：

1. 每段是否在推进动作、关系、信息或决定？有没有纯解释段？
2. 视角是否稳定？有没有视角人物不该知道的信息？
3. 对话是否带诉求？遮住名字能否认出是谁在说话？
4. 场景该展开的是否被 summary 带过？该压缩的是否写成了流水账？
5. 章首是否进入具体处境？章尾是否停在变化上？
6. 连续两章是否用了同一种钩子或同一种爽点模式？
