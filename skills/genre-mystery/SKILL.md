# 悬疑 / 灵异 / 规则怪谈

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**在信息不足下仍然能推理的恐惧**：规则可以被发现、被试探、被利用，而不是作者临时说了算。

- 核心快感：发现规律、验证规律、用规律活下来。
- 恐惧来源：未知的边界、违反规则的代价、同伴不可信、时间与空间被改写。
- 作者要先回答：这个"鬼"或"规则"的触发条件、优先级、例外分别是什么？

## 核心循环

```text
异常现象（读者和主角同时察觉）
→ 收集线索（目击、记录、试验、他人说法）
→ 提出假设（可能错）
→ 用低成本方式验证（试探、对照、牺牲小东西）
→ 规则成立/被推翻，代价出现
→ 更大的规则或更深的原因浮出
```

线索必须公平：读者回头能看见。主角不能靠"突然想到"破局。

## 开篇（前三章）

1. **第一章**：先给一个具体的异常画面或事件，不要先讲背景设定。让读者产生"哪里不对"。
2. **第二章**：给出第一条可验证的规律，并让主角付出一次小代价（受伤、失去物件、被警告）。
3. **第三章**：让读者意识到规则不止一条，或规则的解释是错的。
4. 开篇避免：鬼一出场就全知全能、旁白解释世界观、纯靠 jump scare 撑场。

## 规则设计

每条规则至少写清：

| 项目 | 问题 |
| --- | --- |
| 触发 | 什么条件下会发生 |
| 表现 | 发生时能被观察到什么 |
| 优先级 | 多条规则冲突时谁生效 |
| 例外 | 什么情况下不成立 |
| 反制 | 人能用什么方式规避或利用 |
| 代价 | 使用或违反要付什么 |

- 规则要能被读者推理出来，允许读者比主角早一步想明白。
- 不要中途改规则救场；要改就提前埋下"规则会变化"的迹象。
- 力量越强，代价越近（身体、精神、记忆、人性、关系）。

## 爽点与钩子

- 爽点不是打赢，而是"看穿"：主角在压力下用一条正确规则翻盘。
- 恐怖节奏：安静 → 异常 → 试探 → 错误判断 → 代价 → 短暂安全 → 更大异常。
- 章尾钩子常用：规则被打破、同伴说了不该知道的事、倒计时开始、发现自己是规则的一部分。
- 每次揭示后要给读者一个新的、更不安的问题。

## 人物与关系

- 队友要有独立判断和私心；恐怖故事里"谁在隐瞒"比"谁最强"更重要。
- 主角的信息边界必须严格：他不知道的事不能靠直觉补上。
- 官方/民间组织要有自己的处理逻辑和掩盖动机。
- 受害者不是道具，至少让读者记住一个具体的人。

## 常见失效

- 规则随意，作者需要时临时加一条。
- 线索全在事后补，读者无法参与推理。
- 鬼无解，主角也没有任何反制手段，只剩逃跑。
- 用战斗数值打鬼，恐怖感消失。
- 只有 jump scare，没有持续的不安。
- 力量没有代价，主角越用越安全。

## 动笔前确认

1. 这一章的规则是什么？读者能从哪里推理出来？
2. 主角现在知道什么、误以为什么、还不知道什么？
3. 这次活下来靠的是哪个前文线索或准备？
4. 付出了什么代价？谁受影响？
5. 章尾留下了什么更不安的问题？
