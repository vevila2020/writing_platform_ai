# 玄幻 / 仙侠升级流

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`；需要清理文风时再用 `novel-deslop`。不要把本卡内容贴给作者，先把它当检查表。

## 读者承诺

读者来这里是看**可感知的变强**：从被压着，到能进以前进不去的地方、能见以前见不到的人、能处理以前处理不了的麻烦。

- 核心快感：境界突破、资源获取、公开证明、宗门/家族地位上升。
- 情绪底色：不甘 → 积累 → 兑现 → 更大的舞台。
- 作者要先回答：这本书的"强"具体改变了什么？如果只改数值，承诺没有落地。

## 核心循环

```text
瓶颈（资源/境界/身份/期限）
→ 寻找功法、丹药、师承、秘境或靠山
→ 取舍与准备（拿什么换、得得罪谁、暴露什么）
→ 突破或越级（来自前文准备，不是临时觉醒）
→ 新权限/新地图/新对手
```

每一轮循环至少改变一项**访问权**：能进的区域、能接的任务、能让谁低头、能对抗的层级。

## 开篇（前三章）

1. **第一章给落差与钩子**：先让读者看见主角被什么压住（资质、出身、婚约、宗门规矩、家族资源分配），再给一个必须抓住的机会。不要在第一章解释完整个力量体系。
2. **第二章给第一次兑现**：可以是小胜、识破、得到关键资源或保住重要的人。兑现必须由主角的选择或准备带来。
3. **第三章给更大的问题**：兑现之后立刻出现新门槛或新对手，让读者知道"变强只是入场券"。
4. 开篇避免：大段境界说明、长辈旁白式世界观、主角被动挨打到第三章。

## 成长阶梯

每个阶段写清五项：

| 项目 | 问题 |
| --- | --- |
| 能力边界 | 现在能做什么、还不能做什么 |
| 社会意义 | 谁能命令他、他能进哪里、别人怎么称呼他 |
| 突破条件 | 资源、领悟、试炼、师承、时间 |
| 代价/风险 | 受伤、欠债、暴露、错过窗口、被更高层注意 |
| 新矛盾 | 这个阶段解决了什么旧问题，又制造了什么新问题 |

- 阶段名称要能被读者记住，但不要只有名字。
- 越级必须有规则：克制、环境、团队、一次性底牌、情报差。
- 旧能力不要作废，让它变成基础、被克制或被制度限制。

## 爽点与钩子

- 优先用"准备被兑现"型爽点：前面埋的丹药、人情、规则漏洞在关键时刻起作用。
- 打脸需要三步：公开场合 + 对方先立起势 + 主角用可回看的依据翻盘。
- 章尾钩子常用：新敌人现身、旧承诺到期、地图开启、身份暴露、资源被夺。
- 每 3–5 章至少一次可见回报；长时间只压制会让读者退订。

## 人物与关系

- 对手要有独立目标与资源，不能只负责送脸。
- 导师型角色要有自己的目的，不能只当功法发放机。
- 同门/家族/道侣的关系要能约束主角的选择，而不是只在旁边惊叹。
- 配角至少有一个自己的欲望；遮住名字后，读者应能认出谁在说话。

## 常见失效

- 只有境界名和数值，没有社会反应。
- 所有问题靠隐藏血脉、突然觉醒或系统提示解决。
- 反派降智，专门等主角准备好再出手。
- 换地图后旧角色、旧关系、旧债务全部消失。
- 资源无限，缺少维护、消耗和稀缺感。
- 主角永远正确，没有任何取舍和代价。

## 动笔前确认

1. 这一章结束时，主角的处境、能力、关系或认知变了什么？
2. 这次变强来自前文的哪个准备？读者能不能回看？
3. 谁看见了这次变化？他的态度会怎么变？
4. 下一步的新问题是什么，为什么现在必须处理？
5. 有没有把通用写作判断（期待、阻碍、选择、后果）写丢？
