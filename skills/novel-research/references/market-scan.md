# 扫榜与方法

扫榜不是「看谁排第一」，而是用一批当前样本回答：这个题材/频道现在靠什么吸引读者，作者自己的作品能借什么。

## 先确定范围

回答任何榜单问题前，先写清下面五项；用户没说就选默认值并在回答里说明：

| 项目 | 说明 |
| --- | --- |
| 平台 | 不限 / 起点 / 番茄 / 晋江 / 七猫 / 知乎盐言。多平台对比时分开列，不混排 |
| 频道 | 男频 / 女频；玄幻、都市、悬疑等具体分类 |
| 榜单类型 | 畅销、新书、推荐、月票、金榜、飙升、完结等；不同榜单含义不同，不能互相替代 |
| 时间窗口 | 抓取日期；区分「当前榜」与「历史榜」 |
| 样本量 | 实际读到几本；少于 5 本时明确说明不能代表整体 |

## 每本书记录什么

只记录页面上能核验的字段：

| 字段 | 来源 | 缺失时 |
| --- | --- | --- |
| 书名 | 榜单页/作品页 | 必填，找不到就不列入 |
| 作者 | 同上 | 写「未获取」 |
| 平台与排名 | 榜单页 | 写榜单名与名次 |
| 题材标签 | 作品页标签/分类 | 写「未获取」，不自行归类 |
| 可见数据 | 榜单页或作品页展示的收藏、推荐、月票、在读、评论数 | 原样记录并注明页面显示的统计口径 |
| 简介/开篇 | 作品页 | 只取短句作为分析依据 |
| 更新与字数 | 作品页 | 写「未获取」 |
| 来源 URL | 实际抓取页 | 必填 |
| 抓取日期 | 当前日期 | 必填 |

不要用「大概」「估计」补数据。搜索引擎摘要里的数字可能过期，不能作为榜单数据。

## 分析维度

样本收集后，按下面几项归纳，每条结论都要能指回具体作品：

1. **开篇承诺**：前三章给读者什么承诺？是升级、复仇、身份反转、情绪补偿，还是解谜？
2. **核心循环**：每章重复的爽点/情绪点是什么？靠什么维持期待？
3. **主角目标与阻力**：目标是否具体？阻力来自人、制度还是环境？
4. **金手指/核心优势**：独特性在哪？代价和限制是什么？
5. **节奏**：多少章一次小兑现、多少章一次大兑现？章尾钩子类型是否集中？
6. **人物关系**：关系网承担什么功能（助力、对照、情感、反派）？
7. **差异化**：同一榜单里，哪几本明显不同？不同在哪一层（设定、人设、节奏、文风）？

## 输出结构

- **结论摘要**：3–5 条，直接回答「现在什么在火、共同点是什么」。
- **样本表**：按平台/榜单分组，字段缺失写「未获取」。
- **共性**：跨作品重复出现的模式。
- **差异与机会**：哪一块还没被写透，作者可以切入。
- **风险**：同质化、审核/平台政策、题材周期。
- **样本限制**：样本量、时间窗口、未覆盖的平台。

## 平台差异（分析口径）

- **起点**：重设定、长线升级、世界观与体系；看新书榜和月票榜能判断长线题材热度。
- **番茄**：重开篇、快节奏、强情绪；看榜单前列的开篇承诺和章均节奏。
- **晋江**：重人物关系、情绪与文笔；标签和评论区信息量大，但数据字段与其他平台不可直接比较。
- **七猫**：重强冲突与爽感密度，免费阅读模式下看留存导向的开篇设计。
- **知乎盐言**：重短篇钩子密度和反转，节奏单位与长篇不同，不能套用长篇章节标准。

跨平台对比时，只比「可核验且口径相同」的字段；排名和收藏绝对值不可跨平台直接比较。

## 不做的事

- 不根据一两本书推断整个题材趋势。
- 不把「榜上靠前」等同于「质量高」或「适合作者模仿」。
- 不预测某本书的后续成绩。
- 不抓取需要登录或违反平台条款的数据。
