# 场景与爽点

解决「这一章 / 这一场怎么写、读者等待的回报如何兑现」。整体结构见 `premise-and-outline.md`，长篇中的场景更新见 `long-form.md`。

## 场景

**怎么做**：先确定场景要改变什么（局势 / 认知 / 关系 / 情绪），再选行动或反应结构。

**行动场景模板**：

```
目标（人物此刻要什么）：
阻力（谁 / 什么阻止，为什么不能绕过）：
选择（可选方案与代价）：
结果（来自前文能力、准备或选择）：
余波（局势 / 关系 / 认知 / 代价的变化）：
```

**反应场景模板**：

```
情绪（对上一个结果的真实反应）：
困境（接受什么、放弃什么）：
决定（下一步行动，以及理由）：
```

**信息边界表**（悬念场景尤其需要）：

| 信息 | 视角人物 | 其他人物 | 读者 |
| --- | --- | --- | --- |
| 谁知道什么 | | | |
| 谁误以为什么 | | | |
| 何时揭晓 | | | |

**检查**：

- 场景结束后，有没有什么东西和开始时不同？
- 选择是否有真实取舍？是否允许局部成功但付出代价？
- 对话是否在推进诉求、博弈或关系，而不是只解释设定？
- 揭晓时，前面的线索是否可以被重新解释？

## 开篇

开篇不是背景介绍，是让读者决定要不要继续读。前 300–800 字至少要让读者知道：

- 谁在什么处境里；
- 他此刻想要什么、被什么挡住；
- 失败或退让的代价；
- 这本书提供的独特体验，也就是题材承诺。

**三种可用开场**：

| 类型 | 怎么开 | 适合 |
| --- | --- | --- |
| 危机中登场 | 人物已经在行动、逃跑或对抗，规则和关系在动作里露出 | 强节奏、生存、战斗、悬疑 |
| 异常日常 | 用具体生活细节建立常态，再放进一个不对的细节 | 都市、日常、慢热、情感 |
| 选择 / 交易 | 人物面对一个必须回应的提议、条件或代价 | 权谋、商战、情感、规则怪谈 |

**前三章分工**：

1. 第一章：建立主角当下目标、核心阻碍和读者追读问题；结尾给出第一次选择或危机。
2. 第二章：展示规则、代价和对手，让读者知道「这件事为什么难」。
3. 第三章：给出第一次可感知的兑现、成长或局势变化；不要连续三章只铺垫。

**开篇检查**：

- 第一段有没有具体的人、动作或异常？还是天气、风景、世界观说明？
- 读者能否用一句话说出主角此刻要什么？
- 设定是否在人物需要它的时候才出现？
- 第一章结尾有没有一个必须翻页的问题？
- 开篇承诺的体验，后文是否真的提供？

## 章首与章尾

章首负责让读者进入当前处境，章尾负责让读者想翻下一页。两者都只服务本章功能和下一章承接，不为凑字数解释。

**章尾类型**（按本章停下的情绪选）：

| 类型 | 停在哪里 |
| --- | --- |
| 危机 | 下章必须回应的威胁或倒计时 |
| 悬念 | 新信息出现，但含义尚未揭晓 |
| 渴望 | 奖励、突破或关系进展已经在望 |
| 选择 | 两个都有代价的选项摆出来，不给结果 |
| 情绪 | 关系变化、背叛、示弱或未回应的请求 |
| 反转 | 身份、动机或认知被推翻 |
| 留白 | 只给反应，不解释发生了什么 |

**章首类型**：

| 类型 | 停在哪里 | 作用 |
| --- | --- | --- |
| 动作中断 | 人物正在做一件事，被新信息或新威胁打断 | 立即进入处境 |
| 对话切入 | 一句带诉求或冲突的台词直接开场 | 建立关系与张力 |
| 异常细节 | 一个不该出现的人、物、声音或数字 | 制造问题 |
| 倒计时 | 期限、追兵或即将发生的公开事件 | 增加压力 |
| 结果余波 | 上一章结果带来的反应、代价或新问题 | 承接并推进 |
| 视角切换 | 换到另一条线，但带着同一问题 | 扩展局面 |
| 物件 / 环境异常 | 通过具体物件变化暗示局势 | 氛围与线索 |

**章首三不要**：不要天气或风景开场，不要前情复述，不要先讲设定再让人物出场。前三章可以更强；日常过渡章不必强行制造危机，但第一段要出现具体的人、动作或异常。

**章尾强度**：

| 章节位置 | 建议 | 注意 |
| --- | --- | --- |
| 前三章 / 卷首 | 强钩子：危机、反转、选择 | 不要用总结或安全着陆收尾 |
| 推进章 | 中强钩子：渴望、悬念、情绪 | 至少留一个未闭合的问题 |
| 过渡章 | 弱钩子可以，但不能没有 | 用关系变化、信息缺口或新目标承接 |
| 卷末 / 大高潮 | 强钩子：兑现后的新问题或更大威胁 | 先给满足，再打开下一层 |

**钩子编排**：

- 同一类型连续使用不要超过两章；危机、悬念、渴望、选择、情绪、反转、留白轮换。
- 即时钩子通常在一到三章内回应；长期谜题可以延后，但每次出现都要给新信息或新代价。
- 钩子停在期待成立的那一刻，不要补一段解释；下一章开头要接住，而不是换场景逃避。

**检查**：

- 章尾是否落在变化上，而不是总结、感悟或「回去休息了」？
- 钩子是否在期待成立的那一刻就停，没有补一段解释？
- 连续两章是否用了同一种钩子？
- 钩子强度是否与章节阶段匹配？过渡章可以弱，但不能没有未闭合的东西。
- 章首是否尽早出现具体的人、行动或异常，而不是先讲设定？

## 爽点

爽点是读者在意的事情得到有分量的回应，不等于打脸或升级。

**爽点类型**：

| 类型 | 读者拿到什么 | 常见写法 |
| --- | --- | --- |
| 信息差反转 | 之前被隐藏的信息重新解释局面 | 主角早已知道，或对手误判 |
| 实力兑现 | 训练、准备或规则理解转化为结果 | 用新用法解决旧问题 |
| 身份揭晓 | 被低估者获得应有的认可或权力 | 见证者在场，后果落地 |
| 关系确认 | 信任、站队、亏欠或距离变化 | 选择、承诺、公开维护 |
| 资源获得 | 物品、渠道、资格或机会 | 有代价的交换或争夺 |
| 认可 / 打脸 | 被看见、被需要、被畏惧 | 先抑后扬，但压抑段仍有行动 |
| 守护成功 | 保护对象或目标得以保全 | 付出代价，允许局部损失 |
| 智斗胜利 | 布局、试探或反制奏效 | 线索可回看，对手不降智 |
| 情绪释放 | 压抑得到回应 | 不靠旁白宣布，落在行动或关系 |

**检查链**：

```
期待（读者具体在盼什么）：
铺垫与阻碍（为什么现在得不到）：
人物行动（用了什么能力、准备或选择）：
兑现（结果是什么，改变了什么）：
余波（谁受影响，下一步怎么来）：
```

**安排表**：

| 层级 | 作用 | 间隔原则 | 例子 |
| --- | --- | --- | --- |
| 即时小回报 | 维持追更 | 每个章组至少有可感知进展 | 拿到关键线索、赢下一次小博弈 |
| 阶段兑现 | 回应本卷期待 | 本卷高潮 | 身份揭晓、关系确认、阶段目标达成 |
| 核心大高潮 | 回应全书承诺 | 结局或大转折 | 主线真相、最终对抗、人物完成选择 |

**期待阶梯**：

- 本章微期待：读者这一章在等什么？每章至少回应一个。
- 本卷阶段期待：这一卷承诺给读者什么？卷末必须兑现，或明确延期的代价。
- 全书核心期待：开篇承诺的体验是什么？终局回应，不能用新地图或新谜团替代。

每次兑现只关闭一层期待，同时打开下一层；不要把三层压在同一章，也不要长期只开不关。

**微兑现**：不一定每个章组都有大高潮，但读者每章都该拿到一点东西。常见类型：

| 类型 | 读者拿到什么 |
| --- | --- |
| 信息 | 新情报、规则被理解、旧信息被重新解释 |
| 关系 | 信任、亏欠、立场或距离变化 |
| 能力 | 新用法、熟练度、限制被突破 |
| 资源 | 物品、渠道、机会、资格 |
| 认可 | 被看见、被需要、被畏惧 |
| 情绪 | 压抑释放、共鸣、心疼或心动 |
| 线索 | 伏笔推进或回收 |

过渡章、低压章可以没有大爽点，但不能整章无收获；通常至少保留一个微兑现，避免读者觉得「这章可以跳过」。

**重复疲劳**：同一种爽点模式连续出现三章以上，读者通常会开始预测。换执行方式（铺垫长短、代价、见证者层级）、换兑现类型，或轮换副线。升级不只看数值，还可以升级规模、对手层级、解决方式和被谁看见。

**写法提醒**：

- 结果要来自前文已有的能力、准备或选择；旁人震惊只能做反应，不能代替结果。
- 先抑后扬时，压抑段要让人物仍在行动、仍有希望或进展；避免长期受辱和反复打断兑现。
- 交替使用胜利、成长、揭秘、情感、幽默与恢复，避免同一种循环。
- 胜利后的新问题应承接成果，不要立刻抹掉刚获得的满足。

**兑现前检查**：

- 读者是否明确知道主角想要什么、失败会失去什么？
- 阻碍是否具体，且不能靠主角「突然更强」绕过？
- 兑现是否来自前文已经展示的能力、准备、关系或选择？
- 有没有见证者或后果，让收益被世界承认？
- 兑现后是否改变了局势、资源、关系或认知？

**兑现后处理**：

- 先让读者拿到满足，再引入新问题；不要立刻抹掉刚获得的成果。
- 新问题从成果里长出来：责任、暴露、嫉妒、更大目标，而不是作者宣布「下一个副本」。
- 配角可以反应、助攻、见证，但不能抢走主角的因果权和结算权。

**检查**：这个爽点兑现的是读者之前被明确引导去期待的东西吗？兑现后，局势、资源或关系真的变了吗？

## 正文表达

- 成功可以是脱身、发现、守护、谈判、克制或接受损失，不必总是击败对手。
- 按需要连接短期疑问、中期秘密与长期谜题；阶段答案要改变读者对更大问题的理解，而不只是再添一个谜团。
- 用具体细节、有辨识度的人物声音和作者选择的视角；压缩重复解释，同时保留能制造张力、情感和氛围的细节。表达高效不等于始终快进。
- 对话要带诉求：试探、回避、施压、诱导、拖延，都比完整回答更像人在说话。允许打断、答非所问和沉默；不同角色有不同的句长、口头禅和回避方式。
- 情绪优先通过动作、生理反应、注意力和决定呈现。直写情绪不是错误，但「他感到愤怒」之后要落到他此刻做不成什么、身体哪里紧了、下一步要做什么。

**去 AI 味**：下面是模型最容易留下的痕迹，写完一段就对照一次。只改表达，不改事实、剧情、人物所知；不要为了「像真人」新增事件、微动作或粗话；作者有意的文风保留。

| 痕迹 | 怎么改 |
| --- | --- |
| 段末总结 / 感悟（「他终于明白了」） | 删掉，落在动作、对话或后果上 |
| 万能副词 + 动作（缓缓 / 淡淡 / 微微） | 换成具体动作、生理反应或不同感官细节 |
| 情绪贴标签（「他感到恐惧」） | 写身体反应、注意力和下一个决定 |
| 全员同一套反应（瞳孔微缩 / 心中一凛） | 给每个角色专属的小动作和说话节奏 |
| 对话一问一答、信息播报 | 加试探、回避、打断、答非所问或沉默 |
| 段落长度和信息密度均匀 | 制造疏密对比；紧张时短句，平静时允许长段 |
| 展示后解释 | 删掉解释句，信任读者 |
| 章末安全着陆 | 至少留一个未解决的问题或不安感 |

**写完一段的五个即时检查**：

1. 这段是否在结尾补了感悟或总结？删掉后是否更利落？
2. 最近三个动作是否都靠「缓缓 / 淡淡 / 微微」修饰？
3. 情绪是告诉读者，还是让读者从行为里看出来？
4. 这句对话是在推进诉求，还是在解释背景？
5. 这一段的节奏是否过于均匀？需要短句、停顿、动作或场景切换吗？
