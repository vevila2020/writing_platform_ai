# 现言 / 甜宠 / 虐恋 / 娱乐圈

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**两个具体的人在现实关系里靠近、误解、选择**：情绪要真，冲突要来自性格与处境，而不是作者硬造。

- 核心快感：心动被看见、误会解开、偏爱被确认、共同面对外部压力。
- 甜宠的基本盘是安全感：男主/女主的偏爱要具体、可验证、有代价。
- 虐恋的基本盘是合理性：读者要理解两个人为什么走不到一起，而不是被强行拆散。
- 作者要先回答：这两个人各自的缺失是什么？对方为什么恰好能补上？

## 核心循环

```text
日常相遇或被迫绑定（工作、婚约、合约、同住）
→ 一次靠近与一次误判（心动 → 退缩）
→ 外部事件推动（事业危机、家族压力、舆论、旧情）
→ 关键选择（坦白、隐瞒、保护、放手）
→ 关系位置变化（更近一步，或裂开一道缝）
```

甜和虐都来自同一套循环，区别只在"选择"的结果与代价。

## 开篇（前三章）

1. **第一章**：给一个有张力的具体场景（相亲、合约结婚、剧组冲突、前任重逢），让两人立刻产生关系。
2. **第二章**：展示性格差异与吸引力来源，让读者相信"这两个人会互相吸引"。
3. **第三章**：抛出外部压力（家庭、公司、舆论、旧伤），把关系变成需要选择的事。
4. 开篇避免：大段人物履历、一见钟情无理由、所有配角都在撮合。

## 情绪与节奏

- 甜宠要"小事件 + 具体照顾"：记住口味、挡一次麻烦、公开维护，比空口说爱有效。
- 虐恋要"误会可解释 + 选择有代价"：不能用一句"你听我解释"就解决。
- 每章至少有一次情绪推进：靠近、退缩、吃醋、心疼、失望、重新靠近。
- 亲密戏服务于关系变化，不要为写而写。
- 事业线与感情线要互相影响：工作选择会改变关系，关系也会影响工作。

## 爽点与钩子

- 甜点要落在具体行为上，避免只靠心理描写。
- 公开场合的偏爱最有效：在谁面前、用什么方式、承担什么后果。
- 章尾钩子常用：一条没发出去的消息、一个被看见的瞬间、前任出现、合约到期、舆论反转。
- 虐点之后要给希望：读者能忍受痛，但不能忍受看不到出口。

## 人物与关系

- 两个人的职业、家庭、经济状况要具体，不能只是"总裁"和"小职员"的标签。
- 男主的强势要有边界，不能用控制代替爱；女主要有自己的判断和事业。
- 前任、家人、经纪人、同事都要有自己的动机，不做纯工具人。
- 关系推进要匹配信任积累，不能跳过沟通直接深情。

## 常见失效

- 甜宠只甜不推进，每章重复同一种撒糖。
- 虐恋靠强行误会和不说人话支撑。
- 男主控制欲被写成浪漫，女主失去主体性。
- 事业线只是摆设，角色除了恋爱没有生活。
- 配角全员助攻或全员恶毒，世界不真实。
- 情绪靠形容词堆砌，没有具体行为和场景。

## 动笔前确认

1. 这一章两人的关系位置是什么？从哪里到哪里？
2. 推动变化的具体事件是什么？是谁的选择？
3. 甜点或虐点落在哪个可验证的行为上？
4. 误会是否合理？角色为什么不能直接说清？
5. 事业线这一章有没有和感情线发生关系？
