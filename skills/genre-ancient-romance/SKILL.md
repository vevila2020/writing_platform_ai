# 古言 / 宫斗 / 宅斗

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**在礼法和后宅的缝隙里争取生存与体面**：女主角不能明着对抗规则，要借规则反击。

- 核心快感：识破算计、反将一军、守住自己人、在公开场合赢下名分。
- 舞台是内宅、宫闱、家宴、庙会、亲族往来：所有冲突都在日常礼仪里发生。
- 作者要先回答：这个女性角色被什么限制？她能调动的资源、人脉、信息各是什么？

## 核心循环

```text
日常秩序（请安、宴席、婚配、掌家、宫中传话）
→ 有人越界或设局（争宠、构陷、抢婚、夺权、下毒）
→ 女主收集信息、辨认站队、找规则漏洞
→ 借长辈、婚约、礼法、外人或公开场合反击
→ 结果兑现，但付出人情或名声的代价
→ 新的敌意与更高的位置
```

冲突要"文斗"多于"武斗"：话说半句、礼数压人、借刀杀人。

## 开篇（前三章）

1. **第一章**：先给一个具体的处境危机（被退婚、被诬陷、要被送进宫、嫡庶之争），让读者立刻站到女主这边。
2. **第二章**：展示女主的判断力和边界感——她不是任人拿捏，也不鲁莽。
3. **第三章**：抬出主要对手和更大的利益格局（婚配、继承、宫位），让读者知道故事要争什么。
4. 开篇避免：大段身世说明、全员蠢坏、女主一开口就震慑全场。

## 权力与日常

- 每个家族/宫廷写清：谁掌家、谁有诰命或宠爱、钱和人事在谁手里。
- 婚配是资源交换：门第、聘礼、嫡庶、年龄、政治关系都要算。
- 名分决定话语权：妾室、庶女、外室、宫女，能说什么、不能说什么完全不同。
- 日常细节要有质感：请安、赏赐、节令、吃食、衣料、药方，但不要堆砌成百科。
- 对手不能降智：她的算计要符合自己的利益和认知边界。

## 爽点与钩子

- 优先用"借规则反击"型爽点：女主用礼法、长辈、婚约、圣意把对手架住。
- 打脸要有观众和后果：赢了这一局，会得罪谁、欠下谁的人情。
- 章尾钩子常用：密信、赏赐异常、婚约变动、宫中来人、旧账被翻、身边人反水。
- 感情线要慢：先有利益绑定和试探，再有信任和心动。

## 人物与关系

- 女主的目标要具体：活下去、护住弟弟、退掉婚事、拿到掌家权、查清母亲死因。
- 男主不是救世主：他的权力要有限制，介入要有代价。
- 配角要有自己的算盘：丫鬟、嬷嬷、庶妹、妯娌、太后，不能只做传声筒。
- 反派可以坏，但坏得有逻辑：她要什么、怕什么、凭什么敢这么做。

## 常见失效

- 只有斗嘴没有斗局：每一章都在吵架，局势没有变化。
- 女主开金手指全知全能，对手集体降智。
- 礼法、嫡庶、婚配制度被当成摆设。
- 宫斗只剩争宠，没有前朝、家族和利益。
- 感情线突兀，男主一见面就无条件倾心。
- 日常细节多但无作用，变成背景资料。

## 动笔前确认

1. 这一章的"局"是什么？谁设的、为了什么？
2. 女主现在的身份能做什么、不能做什么？
3. 她借了谁的力量？欠下了什么？
4. 结果在谁面前兑现？名分或处境变了什么？
5. 感情线这一章推进了哪一小步？是否过快了？
