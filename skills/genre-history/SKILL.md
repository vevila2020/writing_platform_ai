# 历史 / 权谋 / 朝堂争霸

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**在规则与名分之内赢得胜利**：不能靠武力一键解决，必须借制度、人心、信息和时机。

- 核心快感：布局、识人、借势、反间、在公开场合赢下名分。
- 世界约束：礼法、官制、军权、财政、舆论、血缘与门第。
- 作者要先回答：这个时代，谁有资格做什么？主角缺的是权力、名分、钱，还是人？

## 核心循环

```text
局势（灾荒、战事、储位、党争、边患）
→ 主角发现一个别人没看到的机会或裂缝
→ 布局（结盟、收买、上书、调兵、放消息）
→ 对手反制，计划出现偏差
→ 公开场合兑现（朝会、军议、审判、战报）
→ 名分与资源变化，新的敌意出现
```

每一步都要有代价：人情、把柄、承诺、兵权、名声，不能只赚不赔。

## 开篇（前三章）

1. **第一章**：给一个具体的权力困境（被夺功、被构陷、家族受牵连、边关急报），让主角必须做选择。
2. **第二章**：让主角用信息或人情完成一次小布局，读者要看到"他懂规则"。
3. **第三章**：把对手抬到有真实权力的层级，战争或朝争正式开局。
4. 开篇避免：大段历史背景讲解、主角一穿越就全知、所有大臣都配合演戏。

## 权力与派系

- 每个派系写清：要什么、怕什么、手里有什么、内部谁不服谁。
- 名分很重要：同样的建议，谁说、以什么身份说，结果完全不同。
- 信息是武器：消息从哪来、谁先知道、谁被瞒着、泄露的后果。
- 财政与后勤要能算账：养兵、赈灾、修河、送礼都要钱，钱从哪来。
- 对手不能降智：他要先于主角布局，或者至少能识破一步。

## 爽点与钩子

- 优先用"借势翻盘"型爽点：主角没有直接力量，但把多方利益拧到一起。
- 公开场合（朝会、军议、审案、誓师）是最好的兑现舞台，要有见证者和后果。
- 章尾钩子常用：密信被截、盟友反水、边关告急、皇帝起疑、旧案重提。
- 每 3–5 章要有一次可见的权力位置变化，而不只是"主角说得对"。

## 人物与关系

- 君臣、同僚、门生、族人、敌将都要有自己的利益计算。
- 主角的道德选择要付政治代价，不能既占道义又毫发无伤。
- 女性角色不应只作联姻工具，可以有自己的消息网、家族立场和判断。
- 让读者记住至少两个对手的名字和手段。

## 常见失效

- 权谋靠现代知识碾压，古人集体降智。
- 只有计谋没有执行：计划永远顺利，没有意外和反制。
- 名分、礼法、官制被忽略，所有人像现代公司开会。
- 战争只有数字，没有粮草、士气、地形和情报。
- 主角道德完美，所有对手都是坏人。
- 朝堂斗争不影响普通人的生活。

## 动笔前确认

1. 这一章的权力关系是什么？谁能让谁做什么？
2. 主角的筹码是什么？他为此付出了什么？
3. 对手的下一步是什么？他为什么会这样选？
4. 兑现发生在谁面前？名分或资源变了什么？
5. 这一章的代价会在哪一章回来找他？
