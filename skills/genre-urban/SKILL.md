# 都市异能 / 隐杀 / 扮猪吃虎

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**现实世界里的越位感**：主角掌握着别人不知道的力量、身份或信息，并在日常场景里被看见。

- 核心快感：藏拙 → 被低估 → 公开证明 → 地位与关系变化。
- 舞台必须是真实的现代社会：公司、警局、医院、学校、媒体、法律、邻里。
- 作者要先回答：主角为什么要隐藏？暴露的代价是什么？没有代价的隐藏只是拖节奏。

## 核心循环

```text
日常场景（工作、家庭、社交）
→ 有人按表面身份轻视或施压
→ 主角用隐藏能力/信息差解决问题
→ 结果被部分人看见，身份裂缝扩大
→ 新的麻烦找上门（组织、警方、旧敌、关系）
```

日常与冲突必须交替。连续打脸会让读者疲劳，连续日常会让期待落空。

## 开篇（前三章）

1. **第一章**：先给一个具体的现实困境（裁员、催债、婚礼、医闹、绑架、公司内斗），再让主角用一次小规模越位解决。读者要立刻知道他"不该这么强"。
2. **第二章**：让越位的后果出现——被调查、被招揽、被要挟、被误解。爽点之后必须留代价。
3. **第三章**：引入更大的组织或旧身份，把"街头级"问题抬到"城市级"。
4. 开篇避免：先讲十年前的组织背景、主角自述辉煌履历、所有配角只会震惊。

## 舞台与身份

- 双面身份要写清：公开身份、隐藏身份、谁知道、证据在哪、暴露后果。
- 城市不是背景板：写清主角的活动半径、常去的场所、能调用的人和信息。
- 现代机构必须真实存在：报警会出警，媒体会报道，公司有流程，法律有边界。
- 资源要有来源：钱从哪来、人为什么听他的、情报怎么拿到。

## 爽点与钩子

- 优先用"信息差 + 现场解决"型爽点：他知道别人不知道的事，并且当场用出来。
- 打脸要有人群反应，但反应要分层：有人信、有人疑、有人记恨。
- 章尾钩子常用：旧身份被认出、关键人物被带走、组织下达新任务、日常关系出现裂缝。
- 避免所有配角在同一章集体改口称赞，这会让世界失真。

## 人物与关系

- 隐藏身份意味着不能对所有人说真话，关系张力来自"我知道但我不能说"。
- 女主/搭档/对手要有自己的判断，不能只负责被救或被震住。
- 反派最好掌握现实权力：职位、资本、舆论、关系网，而不是只会带人堵门。
- 日常角色要有自己的生活，否则日常戏会变成布景。

## 常见失效

- 都市只是换皮奇幻：没有任何现代机构、法律或舆论约束。
- 主角全程无敌，没有取舍、没有暴露风险。
- 扮猪吃虎拖得太久，读者等不到兑现。
- 女性角色只有外貌和崇拜。
- 每章都是同一套打脸流程，核心体验没有升级。
- 主角的能力没有限制，导致冲突无法成立。

## 动笔前确认

1. 这一章的日常场景是什么？它为什么值得写？
2. 主角隐藏了什么？这一章有没有让裂缝扩大一点？
3. 这次兑现来自哪个前文准备或信息差？
4. 谁看见了？他的反应会带来什么后续？
5. 现代机构在这一章里是否按现实逻辑运转？
