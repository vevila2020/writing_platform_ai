# 本章细纲模板

细纲是正文的章节蓝图，写给作者和写手看：写情节，不写清单。文件放在 `setting/chapter-plans/`，平铺章使用 `ch00001-opening.md`。分卷或分节重用章号时，依次带上祖先的 order，例如正文 `chapters/v00001-book/ch00001-night/s00001-door.md` 对应 `v00001-ch00001-s00001-door.md`。不得让同一前缀命中多份细纲。

## 模板

```markdown
## 细纲（第 N 章）

### 第 N 章：{章名}

- 核心事件：{一句话讲本章发生了什么}
- 字数目标：{X} 字
- 所属章组 / 剧情段：{章组文件名或卷纲里的段名}，{本章在该段里承担哪一步}
- 目标情绪：{读者从什么情绪走到什么情绪；不要只写“热血”“悲伤”}
- 主角目标 / 关键选择：{主角本章要什么；必须做出的判断或取舍}
- 章首钩子：{用什么场面或哪句话开场；过场章可写“弱钩子，功能是……”}
- 爽点 / 微兑现：{本章读者拿到什么；过场章可写“无显性爽点，功能是……”，但仍要有一个往下看的理由}
- 章尾钩子：{停在什么场面或哪句话上；强/中/弱；下一章怎么接}

#### 这章怎么走

- 起因：{本章的事为什么发生}
- 发展：{冲突怎么推进}
- 转折：{信息、关系或局势哪里变了}
- 高潮：{情绪或动作最高的地方；过场章写“本章无高潮：{功能}”}
- 结尾：{最后落在谁的什么动作、画面或台词上；写具体落点}

#### 分场

- 第一场：{在哪、谁在场、约多少字；这场改变了什么}
- 第二场：{同上；一章通常两到四场，松的章可以一场}
- 定调的话：{可选，每场一句定调台词或画面；写手可以改字，意思不改}

#### 情节安排（多线）

- 主线推进：{本章对主目标的推进}
- 辅线推进：{按章组/卷纲的线名写“某条线从哪一步推到哪一步”；确实没有写“无”，连续几章不许都是“无”}
- 感情线 / 关系线：{有感情线时写所处阶段和本章推进；没有写“无显性，但关系变化为……”}

#### 人物关系和出场顺序

- 出场顺序：{角色、势力、关键物件按实际出现顺序}
- 人物关系变化：{这章前 → 这章后}
- 视角 / 信息差：{谁知道什么；读者知道什么；主角误判什么}

#### 情节细化

| # | 情节点（谁做了什么） | 作用 |
| --- | --- | --- |
| 1 | {主角在账单上发现 4800 元转出，当场算出等于几个月房租} | {信息揭示} |

“作用”写这一点干什么：铺垫 / 高潮 / 爽点 / 打脸 / 人物塑造 / 设定。点数按需要定，不按目标字数除以点数反推。

#### 结尾设定和钩子

- 结尾设定：{落到什么具体动作或画面；没解决的问题；下一章往前推的力}
- 章尾钩子：{停在什么场面或哪句话上；写具体内容；强/中/弱}

#### 可选：需要时再写

- 这章不能说破：{确有一件具体的事要压住时才写，例如“信是谁寄的先不露”}
- 原样出现的原话：{确有一字不差进正文的原话才写，一行一条，注明在第几点}
- 本章标价：{得失折算成读者已知的什么}
- 闭环状态：{获得 / 使用 / 见效 / 估值走到哪一拍}
- 可以放开写的地方：{本章最值得由写手发挥的几处}
- 有没有硬伤：{只在让章组/卷纲的“有没有硬伤”变化时写；没问题 / 要补 / 有硬伤}
```

## 填写要求

- 核心事件、目标情绪、主角目标 / 关键选择、章尾钩子、字数预算必须有实际内容，不能填 `[待补充]`、`无` 或保留模板占位。
- 作者给范围时添加 `字数范围：2000-2600`；未给就省略整行，目标数值来自本书约束或当前约定。作者本轮范围优先，不能用旧目标覆盖。
- 章首钩子、爽点、章尾钩子写具体场面或那句话，不写“危机钩子”“悬念钩子”这类类型名，也不照抄参考示例句。
- 情节点表默认三列；某个点确要限定写到什么程度（例如能不能当场算价钱）才在表末加“分寸”列，只填需要的行。
- 伏笔写内容，编号只在 `tracking.md` 和卷纲里出现，例如“那封信的去处”。
- 细纲是作者会打开的文件：不写脚本名、字段口径、内部编号、流程说明和检查记录。

## 缺少字段时

旧细纲不强求补齐全部模板；核心事件、目标情绪、主角目标 / 关键选择、章尾钩子和字数预算缺失时，先在既有方向内补齐并运行 `check_writing action=plan`。章组与卷纲也不能确定本章走向时，先给作者具体选择。

## 细纲与正文的关系

- 细纲是唯一剧情蓝图；正文可以调整场景执行和台词，但不能自行增加细纲外的主线事件、反转或人物决定。
- 正文里新长出的具名配角、势力、能力新用法、伏笔、关系或承诺，按 `skill://novel-serial/references/workflow-chapter.md` 的“新增事实的处理”分类登记。
- 细纲没写成的事，记进章组计划或细纲的待补项，不静默丢失。
