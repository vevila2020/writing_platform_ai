# 年代文 / 种田 / 经营 / 基建

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**在受限的年代与资源条件下，把日子一点点过好**：积累要慢、要算账、要有生活质感。

- 核心快感：从无到有、把烂牌打好、家人关系变好、在集体里挣得体面。
- 时代是硬约束：票证、户口、工分、单位、政策、交通、信息都要真实。
- 作者要先回答：这个时代允许主角做什么？他现在最缺的是钱、粮、关系，还是身份？

## 核心循环

```text
生活困境（缺粮、缺钱、分家、招工、灾年、被排挤）
→ 发现一个小机会（副业、手艺、信息差、政策松动）
→ 计算成本与风险，动员家人或伙伴
→ 执行，遇到现实阻碍（人手、材料、审批、邻里眼红）
→ 获得可见改善（吃上肉、盖房、供孩子读书、评上先进）
→ 新的目标与新的矛盾
```

积累必须可追踪：钱、粮、工具、人情，每章都要有变化。

## 开篇（前三章）

1. **第一章**：先给一个具体的生存困境（断粮、分家、被顶替、孩子生病），让读者关心这一家人怎么过。
2. **第二章**：让主角用一件小事证明能力（做饭、修东西、找门路、算账），但不要一步登天。
3. **第三章**：引入更大的约束（大队、厂里、政策、亲戚），把个人问题变成家庭与集体问题。
4. 开篇避免：时代背景大段讲解、主角一上来就靠现代知识碾压所有人。

## 时代与生活

- 写清时代坐标：年份、地点（城市/农村/厂矿/兵团）、家庭成分、单位或大队。
- 资源要具体：粮票、布票、肉票、工业券、自行车、缝纫机、收音机。
- 制度要真实：工分怎么记、招工怎么定、供销社能买什么、政策什么时候变。
- 生活细节要能干活：怎么做饭、怎么攒钱、怎么走亲戚、怎么送礼。
- 时代限制不是背景板，要真正阻挡主角的计划。

## 爽点与钩子

- 优先用"积累兑现"型爽点：前文攒下的钱、手艺、人情在关键时刻派上用场。
- 改善要可见：桌上多一道菜、家里添一件东西、孩子穿上新衣。
- 章尾钩子常用：政策风声、亲戚上门、名额被抢、意外花销、邻里举报、单位调令。
- 家庭矛盾要有层次：婆媳、妯娌、分家、偏心，不能只靠外人使坏。

## 人物与关系

- 家庭成员要有各自的立场：想分家、想供孩子、想进城、想守着一亩三分地。
- 邻里与集体不是背景：生产队、厂办、居委会都有话语权。
- 主角的能力要有边界：他懂现代知识，但要受材料、政策、身份限制。
- 感情线服务于生活线：一起过日子，比轰轰烈烈更符合题材。

## 常见失效

- 年代只是滤镜，票证、政策、单位制度全不生效。
- 主角靠"未来知识"无成本碾压，失去真实感。
- 积累太快，几章就发家致富。
- 家庭关系只有极品亲戚，没有温情与磨合。
- 生活细节靠罗列，不推动情节。
- 时代苦难被消费，没有对普通人处境的尊重。

## 动笔前确认

1. 这一章的生活目标是什么？读者能看到具体改善吗？
2. 时代约束在哪一处真正挡住了主角？
3. 钱、粮、人情账有没有变化？
4. 家里谁支持、谁反对？为什么？
5. 下一个更大的机会或风险是什么？
