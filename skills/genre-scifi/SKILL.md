# 科幻 / 末世 / 星际 / 废土

这张卡只补题材差异。通用结构、场景、人物判断仍按 `novel-craft`。

## 读者承诺

读者要的是**在新技术或新环境规则下做人的选择**：技术不是背景，它改变资源、权力和代价。

- 核心快感：理解规则、利用规则、承担规则的后果。
- 环境必须是压力源：能源、氧气、辐射、食物、距离、通讯、法律失效。
- 作者要先回答：这项技术/灾难改变了什么日常？谁因此得利，谁因此失去？

## 核心循环

```text
环境压力（资源、威胁、期限）
→ 发现机会或异常（遗迹、信号、技术、幸存者）
→ 做出取舍（带谁走、用什么换、暴露什么）
→ 执行并付出代价（设备损坏、人员牺牲、承诺破裂）
→ 环境与权力格局变化
→ 更大的威胁或真相
```

## 开篇（前三章）

1. **第一章**：给一个具体的生存/技术困境，不用先讲世界观。
2. **第二章**：展示规则的边界——能做什么、代价是什么。
3. **第三章**：把个人问题扩大为集体或制度问题。
4. 开篇避免：开场大段设定说明、技术名词堆砌、主角一开局就掌握全部真相。

## 环境与组织

- 生存资源要能算账：水、食物、能源、弹药、药品、备件。
- 距离和通讯是真实约束，不要凭空瞬移或随时联络。
- 组织形态要有逻辑：军队、公司、教团、幸存者聚落、殖民地政府，各自的规矩不同。
- 技术要有边界和副作用，不能需要时万能、不需要时消失。
- 废土/末世要注意：旧世界秩序如何崩塌、现在靠什么维持。

## 爽点与钩子

- 优先用"知识/准备被兑现"型爽点：前文铺垫的设备、协议、情报在关键时刻救命。
- 科技解谜要公平：读者能根据已知信息跟上推演。
- 章尾钩子常用：信号来源不明、补给耗尽、组织背叛、环境突变、旧世界真相。
- 每次解决问题都应消耗资源或暴露位置。

## 人物与关系

- 团队里要有不同立场：想留下、想离开、想重建秩序、想复仇。
- 科学家/工程师不是工具，要有自己的伦理困境。
- 敌人可以是环境，但一定要有人类对手推动冲突。
- 关系要在压力下变化：信任、牺牲、分道扬镳。

## 常见失效

- 科幻只是换皮玄幻，技术没有社会后果。
- 设定自洽性差，前后规则矛盾。
- 资源无限，生存压力消失。
- 所有问题靠主角灵光一闪。
- 组织只是名字，没有制度和利益。
- 末世只剩打怪，没有重建与人性选择。

## 动笔前确认

1. 这一章的环境压力是什么？读者能感觉到吗？
2. 主角动用了哪项技术或准备？代价是什么？
3. 资源清单有没有变化？
4. 谁因为这次选择得利或受损？
5. 下一个更大的问题是什么？
